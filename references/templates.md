# 模板：固定视觉语言，不固定构图

模板只有一个概念：一份规范，加它需要的素材。`design.md` 是入口，含自然语言和构建器读取的 JSON；`layouts.css` 只提供基础样式与可选视觉角色，不要求维护整套 HTML 页型骨架。

## 选用

- 用户指定模板名／品牌：从 `designs/*/design.md` 与 `data/templates/*/design.md` 的名称匹配并读取；只列目录及名称，不默认加载全部素材。重名、无匹配、品牌对应多个模板时询问，不猜测或静默退回默认。
- 未指定：先列出实际可用模板供选择，并提供“不使用模板”；不在叙事大纲阶段为了做大纲先问配色。已有成品小改沿用其当前模板。
- 不使用模板：为本次写独立风格契约，不自动保存成公共模板。
- 公共通用模板与明确获准分发的品牌示例放 `designs/<slug>/`；未获授权的品牌私有模板及素材放 `data/templates/<slug>/`。后者由现有 `.gitignore` 的 `data/` 排除，不能仅为构建方便把私有素材移入公共目录。
- `D Dark` 是公共无品牌示例；`Deepleaper Dark` 是获准公开分发的品牌示例，位于 `designs/deepleaper-dark/`，附原始 PNG 与明确标注的透明白字派生 PNG，不宣称真矢量 SVG。用 `example/deepleaper/deck.json` 构建虚构演示。历史 `gray-orbit` 是独立保留的兼容设计，旧清单不强制迁移。

## 三层约束

| 层次 | 保存什么 | 制作时如何处理 |
|---|---|---|
| 固定项 | 颜色用途、字体家族与层级关系、Logo原貌与留白、封面／正文纹理分区、标题区对齐关系 | 全稿共用；用户本次明确要求才能覆盖 |
| 默认值 | 字号／行距、边距、标题区高度、纹理强度、色块比例 | 先用 tokens；长标题、截图、密集图表需要时可按内容微调，在 plan.md 记录；不能每页另起风格 |
| 自由项 | 主视觉、构图、图表、卡片数量、图片位置；新拟大纲时是否需要副标题 | 按内容关系决定；已确认的页数、副标题与页面分工不属于可擅改项，不能把模板当成固定三栏卡片或固定封面主视觉 |

同一套风格应能支持流程、关系、证据、对比、强文字等构图。可使用基础 CSS 的 `.slide-title`、`.slide-subtitle`、`.brand`、`.surface`、`.texture-card`、`.brand-fill` 等视觉角色，也可用等效命名；改变类名不等于实现规范。

## 使用素材与构建

1. 读取选中模板的 `design.md`、必要的 CSS 与所需素材；按素材清单选正确版本，不猜文件名、不重绘 Logo。
2. 将用到的素材复制到本次内容目录再引用；构建器要求图片留在内容目录内，并将其内嵌为离线资源。内嵌 SVG 保留 `viewBox` 大小写，Logo不拉伸；裁去源画布空白不裁掉图形。
3. 在本次 `plan.md` 记录模板路径、固定项、调整项、素材用法；需要扩展构图时使用项目自己的 CSS，不回写模板。
4. 调用 `scripts/build.py --manifest <内容目录>/deck.json --design <模板目录>/design.md --out <新文件>`。构建器不自动复制素材，也不替制作者决定布局。
5. 浏览器验证固定项与内容表达两条线；模板命中不等于整稿质量通过。逐页核对已确认副标题是否在标题区上屏，不能只在讲稿中保留。品牌素材既查加载，也查比例、清晰度与约定的视觉角色；若封面以品牌符号为主视觉，不得缩成不起眼角标。仍须检查全稿截图、可读性、离线资源及播放编辑功能。

## 保存或更新

支持用户提供规范＋素材新建，也支持从满意成品提炼。保存前先列“固定／默认／自由”三栏，避免把单次内容和像素位置写成永久规则。

- 新模板：确定名称及公私归属，在新目录写 `design.md`、基础 CSS 和资产清单；不覆盖已有同名目录。
- 从成品提炼：只提炼已经认可的样式；去掉客户标题、真实截图、项目专用类名与逐页绝对坐标。验证用另一套内容／不同构图仍成立。
- 私有模板的规范、字体、Logo、素材一起保存在 `data/templates/`；字体仅保存获准分发的文件，否则记录系统字体和替代字体，不下载或再分发授权不明的字体。
- 更新旧模板：先看现有内容与引用关系，说明变更范围；本次页面微调不自动变成永久模板变更。

## 已知失败边界

- 原品牌蓝适合小色块＋白字，不适合直接充当深底小号文字或细线；按角色使用更亮的辅助蓝，不把整套色阶硬替换为原色。
- 封面满幅纹理，正文统一标题区纹理；内容区不铺满，只有有意强调的卡片／色面按需加纹理，不能每个组件重复叠材质。
- 中文封面标题的推荐行距是约 1.09，不把 1.04 或固定换行强套所有字体；浏览器看实际两行间距和标题／副标题留白。
- 内容页不重复左上项目路径／长页眉；标题上移后仍要给右侧 Logo 留宽度。长标题优先重排或缩小一档，不压住 Logo。
- 标题组内适度紧凑、组间留白更明显；不要把页顶和主副标题间距同时压到极小，再在正文前留一大段空白，造成标题区与正文脱节。具体数值读所选模板，长标题／多行副标题联动调整，无副标题收回空位，不把单行样稿坐标强套全稿。
- 细斜纹在缩放、压缩、投影时可能产生摩尔纹；只有浏览器检查时不能声称投影已通过。
