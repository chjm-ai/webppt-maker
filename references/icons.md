# 图标：先选语义，再取素材

## 选库，不临场画通用符号

| 库 | 何时选 | 官方目录／许可 | 本地可用范围 |
|---|---|---|---|
| **Lucide** | 默认商务、流程、工具说明；24px 线性风格 | https://lucide.dev/icons/ ；完整 ISC／衍生版权说明见本地 LICENSE | `assets/icons/lucide/`，24 个常用语义 |
| **Phosphor** | 希望轮廓更柔和、适合教学或生活主题；本地固定 regular 变体 | https://phosphoricons.com/ ；MIT | `assets/icons/phosphor/`，24 个常用语义 |
| **Tabler Icons** | 前两库缺少所需专业对象时，检查其 outline 目录 | https://tabler.io/icons ；MIT：https://github.com/tabler/tabler-icons/blob/main/LICENSE | 未打包；按需从官方仓库取 SVG，不接 CDN |

本地是精选子集，不是全库。每套演示只选一个通用库和一个变体；若设计原先固定 Lucide，而本次要换 Phosphor，在 `plan.md` 明确整组覆盖，不把两库混用。品牌 Logo 只用经核实的官方品牌素材，不拿通用图标冒充。图标库不能替代真正的插画、产品图或科学剖面。

## 主动选择的触发点

逐页草图时检查：**对象／角色／动作／状态能否被一个熟悉符号更快识别？** 适合时主动取用，不等用户逐个指定；在视觉转译表补“语义 → 库/名称 → 放置位置／重复规则”，不适合则写“无图标：理由”。

- **输入与交接：**邮件、附件、资料等放在真实路径入口；AI 与人工放在责任泳道入口。同一对象跨页复用同一符号，使观众沿路径找得到它，而不只是每个标题前贴一个。
- **自然与空间：**太阳、云、水滴可作空间图中的对象锚点；蒸发／凝结方向仍由有依据的路径表达。不要用水滴颗粒把看不见的水蒸气画成可见液滴。
- **验证与风险：**问号表示待确认，警示表示风险；锁表示权限主题，**不表示已安全**。未验证的关卡不放完成勾、盾牌勾或成功绿；“需要确认”不等于“已经确认”。
- **图表与原话：**已有清楚单位、系列名、数轴的定量图不强加硬币／人物点阵；无依据的引用页允许零图标。图标的数量、大小、重复次数不暗示没有来源的数值或重要性。

不用固定图标配额。图标能丰富语义层，但信息关系仍要靠比较、路径、比例、层级等骨架表达；“卡片＋图标＋段落”不是新的可视化。

## 直接取用（全离线）

在技能目录执行，`--out` 是**内容目录内尚不存在的子目录**；脚本不联网，不修改已有目录。

```bash
# 先查真实名称，支持中文关键词；不加 query 列出精选目录
python3 scripts/icons.py --library lucide --query 人工
python3 scripts/icons.py --library phosphor --query 云
# 一次复制本套实际需要的图标及完整许可、选用清单
python3 scripts/icons.py --library lucide \
  --names mail paperclip bot user-round circle-question-mark \
  --out /path/to/content/assets/icons
```

每个 SVG 的 `<metadata>` 已包含完整许可与固定版本来源，`sources.json` 同时保存上游原件与本地版本 SHA-256。复制／内嵌 SVG 时**保留 metadata**，源码包同时保留 LICENSE 和 sources.json；构建器会内嵌本地图片，不另加联网运行时。不要仅复制 SVG 的 path 丢掉许可。

使用内嵌 `<svg>` 时可用 `currentColor` 跟随 CSS tokens；图标设 `aria-hidden="true"`，相邻可编辑 HTML 写可见名称。用 `<img>` 时 currentColor 不继承页面颜色，默认会黑色：需换色就用内嵌 SVG，不用随意滤镜补救。装饰图 `alt=""`，独立承载含义的图必须有名称；不要把关键状态只藏在颜色里。

建议在本次布局 CSS 定义统一的对象／辅助两级尺寸 token（如 `--icon-object`、`--icon-label`），同级图标使用相同外框和视觉重量，不逐个放大撑空白。Lucide 线宽沿用 2；Phosphor regular 是填充轮廓路径，**不能用 stroke-width 硬改成 Lucide**。连接线连到节点容器，不穿过图标或文字。

精选目录没有所需对象时，先查选定库的官方目录与真实文件名，再从固定提交下载所需 SVG 和完整许可，记录 URL、版本、SHA-256，保存到内容目录。联网只发送公共图标名称，不发送业务资料；下载不可用就用明确文字节点，不猜文件名、不手绘近似的品牌／通用符号。

## 看实际截图验收

- 看得出图标在标识什么对象／角色吗？同一对象是否一致、有文字标签？
- 节点图标有没有参与路径定位，而不只是页角摆件？去掉图标后关系仍成立吗？
- 是否把未知画成完成、把权限主题画成安全背书，或用数量暗示数据？
- 小图可辨、线宽与颜色一致，标签不碰撞；去掉纯装饰图标，不靠增加数量打分。
- 断网播放、保存再打开后图标和许可仍存在；关键标签仍可编辑。
