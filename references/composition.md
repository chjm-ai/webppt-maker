# 构图与信息关系检查

| 信息任务 | 建议主体 | 禁止误读 |
|---|---|---|
| 建立主题 | 大标题＋自绘主题几何，非资料堆叠 | 视觉隐喻不能当技术架构 |
| 多输入与多动作 | 两侧分支＋中心规则，线连接模块边缘 | 非逐条已验证映射须注明分析重组 |
| 操作证据 | 大截图＋窄旁注，形成面积差异 | 截图不证明准确率或当前版本可用 |
| 复用与核对 | 横向步骤＋放大的检查关卡 | 人工建议不画成自动回退能力 |
| 结论与证据强弱 | 强文字判断＋分层证据或观察／待核对照 | 无法证明的结果不能用刻度伪造置信度 |

## 出图前

- 五页缩略图能否一眼区分结构，而不是只有不同标题？
- 无图页是否表达了关系，还是把原文切碎装进同样的盒子？
- 箭头是否落在模块边缘，是否穿字？回路／并列／因果是否与来源相符？
- 主次能否通过位置、面积、字号、留白识别，而不是靠加更多颜色？
- 图标是否可解释；不认识图标时，正文是否仍完整？
- 原截图是否清晰、完整，昵称去标识是否保留？
- 封面不动时是否完整？动效是否响应 prefers-reduced-motion？

这是一份制作与目视验收规则，不是构建器已实现的自动审美评分。
